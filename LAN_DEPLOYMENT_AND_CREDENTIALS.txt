3. STEP-BY-STEP LAN DEPLOYMENT (FIRST-TIME SETUP)
--------------------------------------------------------------------------------

STEP 1: Open Port 8000 in Windows Firewall
  1. Locate the file: D:\THAMARAYYATH\setup_windows_firewall.bat
  2. Right-click the file and select "Run as Administrator".
  3. A prompt will confirm:
     [SUCCESS] Port 8000 is now open on Private/Domain LAN networks!

STEP 2: Verify Your Windows Network Profile is "Private"
  Windows Firewall blocks incoming traffic if your Wi-Fi or Ethernet connection
  is set to "Public Network".
  To verify:
  1. Open Windows Settings -> Network & internet -> Wi-Fi (or Ethernet).
  2. Click on your active connected network name.
  3. Under "Network profile type", ensure "Private network" is selected.

STEP 3: Identify This Workstation's LAN IP Address
  In PowerShell or Command Prompt, run:
    ipconfig
  Look for your active adapter (e.g., "Wireless LAN adapter Wi-Fi" or "Ethernet")
  and note the "IPv4 Address", for example:
    IPv4 Address . . . . . . . . . . . : 192.168.1.7 (Current Active LAN IP)

8. TROUBLESHOOTING COMMON LAN ISSUES
--------------------------------------------------------------------------------

Q1: Client PC says "This site can't be reached" (ERR_CONNECTION_TIMED_OUT)
  - Solution 1: Check Windows Firewall. Re-run `setup_windows_firewall.bat` as
    Administrator.
  - Solution 2: Verify both the server workstation and the client PC are on
    the same Wi-Fi network / subnet.
  - Solution 3: Ensure your network connection profile on the host is set to
    "Private" (Windows Settings -> Network -> Wi-Fi -> Private).

Q2: The IP address changed after restarting the Wi-Fi router
  - DHCP routers may assign a new local IP after restart.
  - Recommendation: Assign a Static Local IP (or DHCP reservation) to the host
    workstation in your router settings so the portal URL remains permanent.

Q3: Port 8000 is already in use
  - To find what application is using port 8000 in PowerShell:
      Get-NetTCPConnection -LocalPort 8000
  - To change the port, edit PORTAL_BIND_PORT in D:\THAMARAYYATH\.env
