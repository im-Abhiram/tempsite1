Data Protection Strategy

PythonAnywhere Free Account Notice: Free hosting does not provide automatic off-site snapshots. Storing backups solely inside your PythonAnywhere home directory does not safeguard against account inactivity or unexpected loss.

Recommended Routine: Download the .sqlite3 database backup weekly and store it in an encrypted off-site vault or company physical backup drive.
Restoration Guide:
  1. Log in to PythonAnywhere Web Console or stop the WSGI process.
  2. Navigate to the portal project directory: cd ~/thamarayyath
  3. Rename current database: mv db.sqlite3 db.sqlite3.old
  4. Upload and replace with your downloaded backup: cp backup.sqlite3 db.sqlite3
  5. Reload the web app from the PythonAnywhere dashboard Web tab.
