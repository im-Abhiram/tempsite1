--------------------------------------------------------------------------------
1. HOW TO RUN THE PORTAL
--------------------------------------------------------------------------------

From PowerShell or Command Prompt inside D:\THAMARAYYATH:

▶ PRODUCTION SERVER (Waitress WSGI — Recommended for LAN):
  .\.venv\Scripts\waitress-serve.exe --listen="0.0.0.0:8000" --threads=8 --channel-timeout=120 config.wsgi:application

▶ ONE-CLICK LAUNCHERS:
  • Batch File:       Double-click start_lan_server.bat
  • PowerShell:       Right-click start_lan_server.ps1 -> "Run with PowerShell"

▶ DEVELOPMENT SERVER:
  .\.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000

▶ PORTAL ACCESS URLS:
  • Local Host:       http://127.0.0.1:8000/   or   http://localhost:8000/
  • Network (LAN):    http://192.168.1.7:8000/ (or check via 'ipconfig')
